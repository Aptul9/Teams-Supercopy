# Teams Supercopy privacy policy

Teams Supercopy copies Microsoft Teams Web messages to the clipboard with their author, timestamp, quoted replies and available images.

## Data handled

The extension reads messages already loaded in the open Teams Web chat to associate the selection with the corresponding messages. This includes author names, timestamps, chat titles, message text, quoted replies and images. It copies the messages requested by the user, including all loaded messages when the corresponding shortcut is used.

The extension does not read the clipboard, browsing history or content on other websites. It does not read or store passwords or authentication tokens.

## Local processing and retention

Messages and image data are processed in the memory of the Teams tab. The in-memory image cache contains up to 32 images and is cleared when the tab is reloaded or closed. The extension does not create a saved chat history or automatically download image files.

Extension storage contains only the preference that enables or pauses enriched copying. This preference remains until the extension's local data is cleared or the extension is removed.

Copied content is placed on the operating system clipboard. Clipboard retention, history and synchronization are controlled by the operating system and the user's settings. Closing or removing the extension does not clear the clipboard or remove copies pasted into other applications.

## Network requests

To embed an image, the extension may request it over HTTPS from the server that already provides that image in Teams. The request communicates normal network metadata, including the IP address, to that server. Existing session credentials are included automatically by the browser only for same-origin requests. The extension does not read or save those credentials.

Microsoft Teams and image providers process these requests under their own terms and privacy policies. The extension does not send chat messages or images to a developer-operated server or an AI service. It contains no analytics, advertising or tracking service and loads no remote executable code.

## Use and disclosure

The data is used only to provide the copying function described above. It is not sold, used for advertising or commercial profiling, or used to determine creditworthiness or eligibility for loans. The developer has no remote access to the copied messages.

Teams Supercopy's handling of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

## User controls

Automatic enrichment can be paused from the toolbar popup. Shift-copy bypasses enrichment. The extension can be disabled or removed through the browser's extension manager. Clipboard contents and copies in other applications must be managed using the controls of those systems.

Users remain responsible for having permission to copy and share the conversation content.
